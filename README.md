# Genéricos El Pastillero

Página web para mostrar productos, apartados y un piloto comercial de medicamentos genéricos.

## ¿Qué hace?

Es una pequeña interfaz para probar la experiencia de compra y análisis básica de un catálogo para El Pastillero.

Esta hecho en:
- React
- Vite
- TypeScript

## Cómo correrlo

```bash
npm install
npm run dev
```
