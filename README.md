# Genéricos El Pastillero

Prototipo web para mostrar un catálogo de medicamentos genéricos y evaluar una prueba piloto en una farmacia.

## Instalar y correr

```bash
npm install
npm run dev
```

Para validar la compilación:

```bash
npm run build
```

## Estructura

- `src/main.tsx` y `src/App.tsx`: inicio y navegación
- `src/types/` y `src/data/`: tipos y datos de ejemplo
- `src/lib/` y `src/hooks/`: cálculos puros y estado
- `src/components/` y `src/pages/`: interfaz y vistas
- `src/styles/global.css`: estilos
